# TikTok Ad Library examples

*Unofficial community examples for the TikTok Ad Library. Not affiliated with TikTok or ByteDance. All trademarks belong to their owners.*

Worked walkthroughs for the tiktok ad library and its sibling, Creative Center Top Ads. Neither page documents a public API on the pages this repository is grounded in (Creative Center has an API section under Creative Tools, but its scope is not described there), so this repository contains no scripts. Each example is a browser procedure with the decisions written out, and a note on what to record so the work is reusable.

## Setup

No installation and no keys. The Commercial Content Library landing page shows no login. Creative Center shows Log in and Sign up, so have a TikTok for Business account ready for Examples 2 to 4. Keep a spreadsheet with columns for ad, advertiser, region, objective, date seen and source page; both tools are point-in-time views and neither is your archive.

## Example 1: look up what a competitor has run

1. Open the Ad Library at library.tiktok.com/ads.
2. Read the FAQs page first. It is short and it tells you what the library includes, which saves you from concluding that a missing ad means a competitor is not advertising.
3. Search for the competitor. Record each result in your spreadsheet with the date you saw it.
4. Open the All ads report for the aggregate view and note anything that changes your read of the individual results.
5. Check the Other commercial content section as well; the library keeps it separate from the ad list, so a search of one does not cover the other.

What this shows: the library is a record, not a ranking. It tells you what ran; it does not tell you what worked.

## Example 2: benchmark a category on Top Ads

1. Open Creative Center Top Ads. Expect a No search results found state; nothing renders until filters are set.
2. Set Region first. Region is a filter, so a benchmark taken for one market says nothing about another.
3. Set Objective to match the campaign type you are planning.
4. Choose Sort by, then narrow with the Likes and Duration filters. Use the keyword search for a product category or a competitor's brand terms.
5. Record the top results with the filter values used, so a colleague can reproduce the view.
6. Repeat per region if you sell in more than one.

What this shows: Top Ads surfaces high-performing auction ads; the filters are the method, and an unrecorded filter set makes the benchmark unrepeatable.

## Example 3: from an ad to its creator

1. Start from an ad you found in Example 1 or 2 and note the account that appears in it.
2. The library does not do creator discovery, so open Creative Center's Influencer marketing entry, which leads to TikTok One, the creator marketplace.
3. Search there for the creator or for creators in the same category, and record what you find next to the ad in your spreadsheet.
4. Treat this as a two-tool workflow: ad research in the library and Top Ads, creator research in the marketplace.

What this shows: ads and creators are separate surfaces on TikTok's side; a tool that joins them saves the second pass.

## Example 4: from an ad to a compliant remake

1. Pick the format you want to reproduce from Example 2.
2. Open Ad Specifications and check that the length and format you saw is one you can submit.
3. Open Ad Policies and check the category is allowed for your product.
4. Read the Creative Center Guidelines for what you may do with content you found there.
5. If you want to produce the creative inside TikTok's tools, Symphony Creative Studio covers text to video, image to video, avatar videos, product remixes and translation and dubbing into 15 languages.

What this shows: what ran is not automatically what you may run; the three policy pages are the gate.
